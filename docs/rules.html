#1949
MotoGP大全 ― WGPから2027年まで

1949年のWGP開幕から2027年の850cc新時代まで。シーズン・ライダー・チーム・メーカー、規則・技術・名勝負を網羅。

概要シーズンライダーチームメーカー王者・記録時代史規則技術マシン図鑑名勝負日本とGPサーキット出典

規則

クラスごとの技術規則の移り変わり。「なぜ変えたか」「結果どうなったか」をセットで整理。

最高峰クラス（500cc → MotoGP）

期間エンジン燃料・重量その他の主な規則狙いと結果
1949–69500cc。気筒数・形式の制限なし（過給機は禁止）—1958年 全面カウル禁止単気筒→多気筒4ストへ発展
1970–2001500cc・最大4気筒・6速1998年 無鉛ガソリン義務化1987年 押しがけ廃止→クラッチスタート多気筒競争は収束、2スト4気筒が標準に
2002–064スト990cc（2スト500ccと混走可）燃料24L→22L（2004年〜）。重量は気筒数別：3気筒以下135kg／4〜5気筒145kg／6気筒以上155kg—市販車との関連性回復。最高速が急上昇

2012–131000cc・最大4気筒・最大ボア81mm燃料21L（CRTは24L）CRT（市販車ベース等の低コスト車）新設参戦台数の確保
2014–15同上Factory 20L・5基・開発凍結／Open 24L・12基Openは統一ソフト使用、軟らかめタイヤ・テスト優遇独自電子制御の優位を燃料・基数で相殺
2016–22同上燃料22L、157kg、年間7基統一ECU・統一ソフト、ミシュラン17インチ、2017年 独立ウイングレット禁止、2018年 エアバッグ付きスーツ義務化電子制御の格差縮小、接戦化
2023同上同上スプリント全戦導入、走行中のフロント車高調整装置禁止、タイヤ内圧規制の本格運用興行性強化、安全性

中間クラス（350cc／250cc → Moto2）

期間クラスエンジン規則特徴
1949–69350cc／250cc気筒数制限なしホンダ250cc 6気筒（RC166）など超多気筒化
1970–82350cc最大4気筒・6速1982年で廃止。最後の王者はアントン・マン
1970–2009250cc最大2気筒・6速2ストV2・並列2気筒が標準。市販レーサー（ヤマハTZ、ホンダRS）で参戦しやすく、若手の登竜門

コンセッション制度（性能均衡措置）

成績下位メーカーに開発・テストの自由度を与える制度。2010年代前半の「未勝利メーカー優遇」から始まり、2024年にコンストラクターズポイント獲得率によるA〜Dの4ランク制へ。年2回見直し。

ランク獲得率（2026年時点）主な内容
A85%以上最も制限が厳しい（テスト・ワイルドカード不可など）
B60〜85%テストタイヤ190本、エンジン8基・開発凍結、空力更新年1回
C35〜60%中間水準
D35%未満テストタイヤ260本、エンジン10基・開発自由、空力更新年2回、ワイルドカード可

2024年導入時の基準は90%／70%／50%。2026年中盤時点でドゥカティ・アプリリアB、KTM C、ホンダ・ヤマハD。
